# Cross-Lingual TTS for Indian Languages: A Benchmark and Inference-Time Duration Estimation Strategies

## Demo Page

This repository contains the demo page for our work.

The demo provides audio comparisons of alignment-free TTS systems for cross-lingual speech synthesis across Indian languages in two directions:

- **English Reference → Indic Generation**
- **Indic Reference → English Generation**
